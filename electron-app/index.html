HOW MEKABOX WORKS

STEP 1: EXPORT YOUR REKORDBOX COLLECTION

Before using MekaBox, export your collection:

  1. Open Rekordbox
  2. Go to File > Export Collection in XML format
  3. Save it somewhere you can find it

STEP 2: SELECT A PLAYLIST

MekaBox shows all playlists in your XML. Pick the one you want to export.

STEP 3: CHOOSE EXPORT MODE

  • Copy tracks only - Just the audio files
  • Copy tracks + XML - Shareable package with all hot cues, beat grids, metadata preserved

STEP 4: YOUR PLAYLIST IS READY

MekaBox auto-prepares your XML. Import directly:

  • Preferences > Advanced > Database
  • Under "rekordbox xml", Browse for your XML
  • Right-click playlist > Import To Collection

STEP 5: SHARING WITH A FRIEND

  1. Zip the exported folder
  2. Send to your friend
  3. They'll find README.txt with instructions

⚠ IMPORTANT FOR RECIPIENTS

If you received a MekaBox playlist, you MUST run the Setup script first:

  • Mac: "Setup (Mac).command"
  • Windows: "Setup (Windows).bat"

This prepares the XML for YOUR computer. Then import into Rekordbox normally.
